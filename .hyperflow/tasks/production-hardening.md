## TL;DR

Fix gates first, then the two critical security defects, then harden auth and data paths, refactor OAuth into a provider registry with a backend callback, repair the frontend (navigation, forms, accessibility, RTL, i18n, tokens, dead code), rebuild tests and CI, rewrite docs, add new providers and passwordless methods, and finish with a scaffolding CLI. Each task lands as its own commit after review.

## Decisions

- OAuth callback moves to the backend. Reason: Apple requires form_post, and server-side state and PKCE are simpler. Frontend callback page becomes a thin redirect target.
- Provider ids move to `linkedAccounts: [{ provider, providerId }]` with a compound unique index. Reason: adding a provider must not touch schemas, DTOs or mappers.
- Spotify is excluded. Reason: its profile endpoint no longer returns email.
- Node floor is 22.12 for the app and the CLI. Reason: commander 15 and tsdown require it; Next 16 needs 20.9.
- Commits carry no AI attribution trailer. Reason: the project's global instructions ban it.
- npm publish is not run. The CLI is verified with `npm pack` and `npm publish --dry-run`; the publish command is handed to the user.
