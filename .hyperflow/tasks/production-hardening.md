## Decisions

- Lanes (2026-09-04): straightforward tasks go to agy gemini-3.8-flash-high; logic-heavy tasks (T08, T09, T11, T12, T13, T21, T24 to T29) go to Claude Opus 5 through claude-delegate; design decisions are written by the orchestrator in `.hyperflow/design/system.md` and implemented by the lanes. Work lands on branch feat/production-hardening and ends in a pull request.

- OAuth callback moves to the backend. Reason: Apple requires form_post, and server-side state and PKCE are simpler. Frontend callback page becomes a thin redirect target.
- Provider ids move to `linkedAccounts: [{ provider, providerId }]` with a compound unique index. Reason: adding a provider must not touch schemas, DTOs or mappers.
- Spotify is excluded. Reason: its profile endpoint no longer returns email.
- Node floor is 22.12 for the app and the CLI. Reason: commander 15 and tsdown require it; Next 16 needs 20.9.
- Commits carry no AI attribution trailer. Reason: the project's global instructions ban it.
- npm publish is not run. The CLI is verified with `npm pack` and `npm publish --dry-run`; the publish command is handed to the user.

- 2026-09-05 00:30: agy failed twice with "dial tcp [2001:4860:4841:400::]:443: no route to host" (IPv6 to daily-cloudcode-pa.googleapis.com). T18 completion rerouted to Opus 5. If IPv6 stays broken on this machine, disable it for the session or prefer Opus 5 for the rest of the queue.

- T24 batch 1 review: Apple can only be exercised with NODE_ENV=production behind HTTPS because the SameSite=None state cookie is tied to production. A dedicated flag for tunnel testing is deferred. Env examples and older setup guides still show the pre-registry callback URL shape; T23 rewrites them.

- T27 review: totp and passkeys import each other at file level (verify DTO and login service), so a generated project with totp but without passkeys will not compile. T30 must run the CLI for the combinations (email only, magic link only, totp without passkeys, passkeys without totp) and either decouple through an interface or mark the dependency in the manifest.

- T28 review: file-level pruning is not enough; deselected features leave alias imports in methods/registry.ts, settings/page.tsx, app.module.ts and the totp/passkeys cross-imports. Decision: features mark their imports and registrations with `// feature:<id>` (single line) or `// feature:<id>:start` / `:end` (block) comments, and the CLI strips those lines for unselected features (T29 follow-up), then builds each combination in CI.
