## Design, edge cases and finishing pass

The new role picker performs one bounded request per page/debounced query while open. Rendering and selection work are O(20) per response; server count/pagination costs are unchanged. Current-query data prevents previous-query metadata from forcing the wrong page. Tests cover first/last/empty states, deletion recovery, later-page availability, selected-state persistence, failure/retry, keyboard access and both locales. No claim is made about every possible role name or concurrent modification.

Configuration helpers use a fixed number of linear passes over template text: O(n) time and additional space. They fail on invalid ports or missing required structures before callers write files. Tests cover supported template variants and idempotency. They are deliberately scoped to the maintained templates rather than a general nginx/YAML rewriting engine.

Async child execution leaves compiler work unchanged; it keeps the test worker responsive. Bounded output, cancellation and timeout behavior have direct regressions. No speedup is claimed.

Code Simplifier guidance was applied to the changed code: small pure configuration functions, existing UI primitives, explicit state and shared subprocess handling. The final pass retained contracts and safeguards without unrelated refactoring. Unslop and Humanizer were applied together to this report.
